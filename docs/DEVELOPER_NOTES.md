# Southern Iron Fitness Interface Rules

## Administration and backend layouts

- Never build administration, trainer, master-admin, or customer-account pages as one long run-on page.
- Organize every major section inside a native, keyboard-accessible accordion.
- When a section contains multiple workflows or large data groups, split its content into nested accordions.
- Accordion summaries must clearly state what is inside and show useful status or item counts when available.
- Keep only the workflow currently being used open by default, especially on mobile.
- Preserve the same information hierarchy and functionality on desktop and mobile.

## Lift Lab workout prescriptions

- Begin with the trainee and display their name/account card before exposing prescription tools.
- Organize prescriptions by program, then workout day/split, then individual exercises.
- Save each exercise immediately to its selected workout day so Madie can repeat the process until the day is complete.
- Trainees log actual sets, reps, weight, perceived difficulty, and a multi-line note for every exercise.
- Madie must be able to review the trainee's completed values and notes from the same trainee prescription card.
